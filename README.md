# AV 파일처리

###### 1.3.31 (2026.10.17): 작업 패널
- 세 모듈의 처리결과 페이지와 YAML 설정 페이지에서 1회 실행, 진행 상태, 실시간 로그, 작업 중단을 지원합니다.
- 스케줄 작업도 각 작업의 패널에 표시합니다. 기본/YAML 작업의 상태·로그·중단 제어는 독립적이며 동시에 실행할 수 있습니다.
- 일반 패널에 폴더를 입력하면 저장된 처리 옵션을 사용해 그 폴더만 1회 처리합니다. YAML 작업은 기존 설정파일 경로 입력값으로 실행합니다.
- 상태 초기화는 작업 종료 후 해당 패널의 진행 상황과 로그를 지웁니다. 처리결과 목록과 설정은 유지합니다.
- 중단은 다음 확인 지점에서 수행합니다. 진행 중인 ffprobe와 외부 요청은 반환될 때까지 기다립니다.
- 최근 300개 로그와 작업 상태는 `/data/db/fp_av_jobs.sqlite3`에 별도 보관하여 로그 로테이션과 관계없이 표시합니다.
